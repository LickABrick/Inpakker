# Inpakker v0.5.1

This patch improves TUI form buttons and keyboard navigation.

- Save, Create and Review actions use the same confirmation-button component as
  Update, with a single focusable button row and no note-card spacing.
- Form fields use the dialog background consistently.
- Empty or invalid text fields no longer block Tab, arrow or Enter navigation.
- Validation runs when the final action is confirmed. An error focuses the first
  field needing attention and preserves the other entries. Fields remain freely
  navigable after a failed submission.
- The behavior applies to application creation, workspace creation/add/relink,
  settings and executable-path forms.

No configuration changes or migrations are required. Windows AMD64 remains the
supported release target. Update with `inpakker update`.
