# v0.6.1

TUI polish and fixes following the v0.6 modernization.

- Keep command palette and filtered-list selections stable during background messages.
- Open application details with Enter from both single and batch operation results, including successful validation.
- Use `V` for Validate all, preserving `v` for the selected application and Ctrl+V for terminal paste.
- Size small forms to their content while keeping larger dialogs bounded and scrollable.
- Keep the footer concise, with full shortcuts in `?` and command discovery in `:`.
- Remove the normal `A` Add workspace shortcut; use Commands to add an existing workspace and `a` for contextual Actions.
- Preserve workspace selection across registry refreshes and keep palette actions tied to their original workspace target.
- Align modal help with Enter, Esc and Backspace behavior and cover modal input isolation with regression tests.

No configuration changes or new external dependencies.
