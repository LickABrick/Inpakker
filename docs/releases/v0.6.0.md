# Inpakker v0.6.0

This release modernizes the terminal interface while preserving the existing
packaging services and workflows.

- Contextual shortcuts, footer hints and help, plus a fuzzy command palette (`:`).
- Consistent visible filtering on Applications, Workspaces, Settings and diagnostics.
- Top-level destination switching without accumulating navigation history.
- Responsive application and workspace previews, with usable narrow layouts.
- Clearer application metadata, grouped settings and readable tool states.
- Workspace Actions (`a`), with Add workspace available through the command palette.
- Selectable diagnostics, action availability reasons, contextual file pickers,
  scrolling indicators and aggregated background activity.
- Preserved direct tool-setup recovery, cancellation and operation result history.

No configuration changes or migrations are required. Windows AMD64 remains the
supported release target. Update with `inpakker update`.
